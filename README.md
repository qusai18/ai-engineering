# AI Governance Risk Dashboard

A local demo app inspired by the Z.ai AI Governance Risk Dashboard space.

## Features

- **Model Registry** — inventory table with search, status filters, KPI cards, and status distribution chart
- **Governance** — policy coverage overview
- **Risk Center** — high/critical attention queue
- **Audit Trail** — recent governance events
- **Export Report** — CSV download of the model inventory
